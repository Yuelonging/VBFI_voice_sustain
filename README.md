# VBFI R-18 语音「消息改行时停止」修复补丁

**版本：v1.0.0**　适用：VenusBlood FRONTIER International（中文版 + R-18 补丁，Kirikiri/KAG3 引擎）

---
## 原始状态
在背景音设置为重复状态(即喘息声on)，喘息声是附加在下一句无配音的台词，因而当切换到下一句无配音台词会中断当前台词(即使是在设置voice sustain为on的情况下)。

## 功能实现
该补丁修改为：台词播放完毕才能播放喘息声，喘息声不能中断台词，但台词可以中断喘息声

## 安装

1. 关闭游戏。
2. 把本文件夹里的 **`data.rar`** 解压并复制到游戏根目录，替换掉"data.xp3"（和 `VBFI.exe` 同一个文件夹）。
3. 启动游戏，进设置把「消息改行时的音色设定」设为**不停止**，进任意 H 场景点一行即可听到变化。


**卸载**：请注意备份原始的 `data.xp3`，原始data.xp3覆盖掉补丁的data.xp3即恢复原状（存档不受影响）。
